# Ai1300TS Monitor v1.1.4

型号不再写死在界面里，改为运行时读取。

## 变更

- **电源型号**：读取 HID 设备字符串（Manufacturer + Product），本机显示 `MSI MPG Ai1300TS`；
  窗口大标题与悬浮卡副标题随设备更新，不再固定为某个型号字符串。
- **显卡型号**：读取 `NvAPI_GPU_GetFullName`，本机显示 `NVIDIA GeForce RTX 5090`；
  首次读取成功后更新“显卡姿态”标题与悬浮卡副标题。
- 读取失败时回退为通用文案（“电源”/“显卡”），不影响监控数据。
- 版本号统一为 **1.1.4.0**。
- README 增加 Contributors：zheng.jiatao、DeepSeek Harness。

## 附件

| `Ai1300TS-Monitor-v1.1.4.zip` | 两个 exe 的压缩包 |

## 功能

- 电源实时数据：输出功率、估算输入功率、转换效率、温度、风扇转速，
  +12 V / +5 V / +3.3 V 电压电流，2 路 12V-2x6 各 6 针电流与告警状态。
- 显卡姿态：俯仰/横滚角，可设基准并监测相对偏移（≥ 0.30° 变色提示）。
- 托盘常驻：悬停显示自绘悬浮卡；关闭窗口隐藏到托盘；单实例，重复启动唤起窗口。
- 登录 Windows 时启动；访问被拒绝时可一键提权重连。

## 兼容性

- Windows 10/11 x64，.NET Framework 4.8（系统自带）。
- 已适配 MSI MPG Ai1300TS 系列电源与 ASUS ROG Astral RTX 5090 P32G Edition 20；
  其他型号的传感器地址/子系统 ID 不同，需要重新适配。
- exe 未签名，首次运行可能触发 SmartScreen 提示。

## 说明

- 电源协议来自对 MSI“UC_Power Supply Unit”插件的 IL 逆向，仅实现读取，不修改电源状态。
