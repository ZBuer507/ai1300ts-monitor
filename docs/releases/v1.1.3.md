# Ai1300TS Monitor v1.1.3

修正显卡型号显示，并统一两个 exe 的版本号。

## 变更

- 显卡型号更正为 **ASUS ROG Astral GeForce RTX 5090 Edition 20**
  （型号 `ROG-ASTRAL-RTX5090-P32G-EDITION20`，32GB）：
  主窗口“显卡姿态”标题、托盘悬浮卡副标题、NVAPI 名称回退与错误提示均已更新。
- 两个产物版本统一为 **1.1.3.0**。
- 其余功能与 v1.1.2 相同。

## 附件

| 文件 | 说明 |
| --- | --- |
| `Ai1300TS-Monitor-v1.1.3.zip` | 两个 exe 的压缩包 |
| `Ai1300TS-PsuMonitor.exe` | 仅电源监控（1.1.3.0） |
| `Ai1300TS-GpuMonitor.exe` | 电源 + 显卡姿态，含托盘悬浮卡（1.1.3.0） |

## 功能

- 电源实时数据：输出功率、估算输入功率、转换效率、温度、风扇转速，
  +12 V / +5 V / +3.3 V 电压电流，2 路 12V-2x6 各 6 针电流与告警状态。
- 显卡姿态：俯仰/横滚角，可设基准并监测相对偏移（≥ 0.30° 变色提示）。
- 托盘常驻：悬停显示自绘悬浮卡；关闭窗口隐藏到托盘；单实例，重复启动唤起窗口。
- 登录 Windows 时启动；访问被拒绝时可一键提权重连。

## 安装

1. 下载并解压，两个 exe 放在同一目录即可（互不依赖）。
2. 运行 `Ai1300TS-GpuMonitor.exe`；若电源 HID 被 MSI 软件占用导致拒绝访问，
   在窗口内点“以管理员身份重开”。
3. 需要开机自启时勾选窗口底部“登录 Windows 时启动”。

## 兼容性

- Windows 10/11 x64，.NET Framework 4.8（系统自带）。
- 仅适配 MSI MPG Ai1300TS 系列电源与 ASUS ROG Astral RTX 5090 P32G Edition 20；
  其他型号的传感器地址/子系统 ID 不同，需要重新适配。
- exe 未签名，首次运行可能触发 SmartScreen 提示。

## 说明

- 电源协议来自对 MSI“UC_Power Supply Unit”插件的 IL 逆向，仅实现读取，不修改电源状态。
